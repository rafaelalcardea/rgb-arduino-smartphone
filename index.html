Comandos para o Arduino

Os botões enviam comandos pela serial. Para funcionarem, o programa do Arduino precisa reconhecer os comandos: LAVA_REAGENTES, LAVA_PERCURSO e START. O botão START inicia primeiro o RGB + vídeo e, em seguida, envia START ao Arduino para reduzir o risco de perder o início do sinal.

O perfil do serial fica separado do RGB. Aqui aparecem apenas dados do fotodiodo lidos do Arduino.

Reprocessamento de vídeo salvo

Carregue um vídeo .webm/.mp4, use a barra para ir até um frame com emissão, selecione/trave o ROI e clique em reprocessar. O intervalo usado no reprocessamento é o mesmo campo “Intervalo RGB/reprocessamento (s)” da configuração do smartphone. Assim, 0,1 s gera pontos a cada 0,1 s; 0,05 s gera pontos a cada 0,05 s.
